## このアプリでできること一覧

このアプリは「VRChat Social Client」として、**PC 上で VRChat のソーシャル周りを全部まとめて見る・管理するためのツール**です。[1][2][3]

***

## 1. フレンドの「今」を見る（Social 画面）

### インスタンスごとのカード表示

- フレンドがどのワールド・インスタンスにいるかを、**インスタンス単位のカード**で表示します。[3]
- 各カードには:
  - インスタンスの公開設定
    - Public / Friends+ / Friends / Invite+ / Invite など。[3]
  - そのインスタンスにいるフレンドの一覧
    - 名前
    - ステータス（JOIN ME / ONLINE / ASK ME / DND / それ以外）
    - お気に入り（★）かどうか
    - 手動ラベル・VRChat Favorite グループラベル[3]

### 並び順のルール

- インスタンスカード自体の並び:
  - 「お気に入りフレンドが多くいるインスタンス」ほど上に来ます。[3]
  - 同数なら、フレンド人数が多いインスタンスが上。[3]
- カード内のフレンドの並び:
  - お気に入り（★）が先に表示。[3]
  - ステータス順: JOIN ME → ONLINE/ACTIVE → ASK ME → DND/BUSY → その他。[3]
  - 最後に名前順でソート。[3]

### フレンドをクリックして詳細へ

- カード上のユーザーをクリックすると、その人の詳細画面（Friend Info / User Info）に移動できます。[3]

***

## 2. フレンド一覧＆ラベル管理（Friend List 画面）

### 全フレンド一覧

- VRChat のフレンドを **オンライン + オフラインまとめて一覧**で表示します。[2]
- 各フレンドの行に出る情報:
  - アイコン（アバターサムネ or プロフィール画像）[2]
  - 名前
  - ステータス（JOIN ME / ONLINE / ASK ME / DND / offline）[2]
  - 今いる場所（`offline` / `private / hidden` / `traveling…` / それ以外は生の location）[2]
  - ユーザー ID（`usr_xxxxxx`）[2]

### 検索・絞り込み

- 検索ボックス:
  - 名前の一部を入力すると、その文字を含むフレンドだけに絞り込み。[2]
- 「Favorites only」チェック:
  - お気に入り（★）を付けたフレンドだけ表示。[2]

### お気に入り（★）機能

- 各フレンドの横の ★ ボタンをクリック:
  - ★ … お気に入りに登録
  - ☆ … お気に入り解除[2]
- お気に入りの情報は、アカウントごとの設定ファイル（userstar）に保存されます。[1][2]

### 手動ラベル（関係性タグ）

- 「🏷 Labels」ボタンを押すと、そのフレンド専用のラベル編集ダイアログが開きます。[2]
- 入力例:
  - `よく遊ぶ, JP, IRL` のようにカンマ区切りで複数登録。[2]
- 表示され方:
  - 最大 2 つまでタグとしてフレンドの下に表示されます。[2]

***

## 3. VRChat お気に入りグループとの連携

### VRChat 側の Favorite Group を読む

- VRChat の「Friend Favorites」（group_0, group_1, group_2 など）を API から読み込んで:
  - それぞれのグループ名（displayName）をアプリ内に表示。[4]
  - Settings 画面で「Group 0, 1, 2」が何人登録されているか、誰がいるかをプレビュー表示。[4]

### ラベルとして反映

- 「この Favorite Group をアプリ側のラベルとして使う」ことができます。[4]
- Import / Auto Sync を有効にすると:
  - 対象グループに入っているユーザーに `vrcFavoriteGroups` という内部情報を付与。[4]
  - Friend List / Social 画面で、そのグループ名をラベルとして表示（最大 3 つ）。[4][3][2]
- ここでは「★（お気に入り）」は直接いじらず、**ラベルだけ**を付けるのがポイントです。[4]

### グループ単位のお気に入り一括操作

- Friend List 画面の下部に、選択している Favorite Group に対して:
  - 「このグループ全員を★にする」
  - 「このグループ全員の★を外す」
- を行うボタンがあります。[2]
- VRChat 側のグループ所属情報と、このアプリ側の★をうまく連携させる用途向きです。[4][2]

## 4. 自分が行ったワールドの履歴（History 画面）

### どんな情報を記録しているか

- VRChat の WebSocket から「自分の location 変更イベント（user-location）」を監視。[1]
- 次のようなタイミングと情報を記録します:
  - `traveling:traveling` → ロード開始。[1]
  - 実際にインスタンスに入ったタイミング:
    - ワールド ID（`wrld_xxxx`）
    - インスタンス ID
    - 入室時刻（`joinedAt`）
    - ロードにかかった時間（`loadMs`）[1]
    - 可能であればワールド名・サムネイル（VRChat API `/worlds/<id>` で取得）[1]

### 履歴の整理

- 前回の履歴と同じワールド・インスタンスだった場合は、新しい履歴を増やさない（連続しないようにする）。[1]
- 履歴は新しい順に最大 100 件まで保存。[1]

### 一緒にいたフレンド

- 自分がいるインスタンスに、フレンドが入ってきた (`friend-location`) 場合:
  - そのフレンドを「friends」のリストに追加。[1]
  - 自分と同じインスタンスにいた時間を計算して `stayMsWithMe` として記録します。[1]

### History 画面での表示

- `userstar:getJoinedInstanceHistory` 経由で履歴一覧を取得。[5][1]
- 画面には例えば:
  - 「5/12 23:40 〜 5/12 24:10 / 30m」というように日付と滞在時間。[5]
  - ワールド名やサムネイル（取得できた場合）[5][1]
  - 一緒にいたフレンド情報は内部に持っており、今後の UI 拡張対象です。[1]

## 5. 背景カスタマイズ

### 好きな画像を背景にする

- Settings 画面の「背景画像を選択」ボタンから:
  - ローカルファイルを選ぶと、それをアプリ全体の背景に設定できます。[4]
- 設定されるもの:
  - 画像ファイルパス（`backgroundImagePath`）
  - ブラー（ぼかし）の強さ（`backgroundBlur`）[4]

### ブラー（ぼかし）調整

- スライダーで 0〜40 の範囲でブラー強度を調整。[4]
- Social / Friend List / History / Settings など各画面は、それぞれの `applyBackgroundFromStore` で:
  - 画像が無い → デフォルトのグラデーション背景
  - 画像がある → その画像を背景 + 指定したぼかしを適用[5][3][4][2]

## 6. 通知機能（特定の人だけ細かく通知）

### どんな通知ができるか

通知対象の「誰」「どういうタイミング」を細かく設定できます。[4][1]

- イベントの種類:
  - オンラインになったとき（online）
  - オフラインになったとき（offline）
  - Public インスタンスに入ったとき（enter_public）
  - +Friends インスタンスに入ったとき（enter_friends）
  - ステータスが変わったとき（status_change）[1][4]
- 通知の送り方:
  - PC のデスクトップ通知だけ（desktop）
  - PC + Discord（desktop_discord）※ Discord 側への送信は webhook URL を使う拡張想定[4][1]

### 通知ルールの設定方法（Settings 画面）

- 「通知ルールを追加」ボタンで新しいルールを作成。[4]
- ルールごとに設定できるもの:
  - ユーザー
    - フレンド一覧から検索して選択（コンボボックス形式）。[4]
  - イベント種別（上記の online など）
  - 通知先（desktop / desktop_discord）
- ユーザー候補リストは、VRChat のフレンド全取得 API を使って自動で用意されています。[4]

### 実際の通知の動き

- VRChat WebSocket からイベントを受け取るたびに:
  - そのイベントに紐づくユーザー ID・種類を見て、通知ルールと照合。[1]
  - 条件に合うルールがあれば:
    - node-notifier を使ってデスクトップ通知を表示。[1]
    - 必要なら Discord Webhook にも送信（拡張可能な構造）。[1]

## 7. アカウント・設定の保存と切り替え

### 保存される設定

アカウントごとに、次のような情報が保存されます。[3][2][1][4]

- お気に入りフレンド ID 一覧（★）
- 手動ラベル（関係性タグ）
- VRChat Favorite Group 情報（どのユーザーがどのグループにいるか）
- 背景画像パス・ブラー強度
- 通知設定（通知ルール）
- 行ったインスタンス履歴（History）
- 起動画面を出すかどうか（Splash ON/OFF）

### アカウント切り替え

- Social 画面の右上のアカウントメニューから:
  - 現在のアカウントの名前・アイコン表示
  - 他のアカウントへの切り替え
  - 新規アカウント追加（ログイン画面へ）[3]
- 切り替えると:
  - そのアカウント専用の userstar ファイル / auth ファイルが読み込まれ、設定・履歴・通知などもそのアカウントのものに切り替わります。[1]

***

## 8. その他の挙動

- Windows のタスクトレイ常駐:
  - ウィンドウを閉じてもアプリ自体は終了せずトレイに残る設定になっています（終了はトレイメニューから）。[1]
- WebSocket 接続の再接続:
  - 接続が切れた場合、自動で再接続・一定時間ごとの再接続ローテーションを行います。[1]
- 起動画面（Splash）の ON/OFF:
  - Settings で切り替え可能で、ON の場合は起動時にスプラッシュ画面 → 各画面へ遷移します。[4][1]
